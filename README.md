# Yz - Aplicativo de Musculação em Casa com Assistente IA (Yzai)

Este é o código fonte da interface do Yz, gerado com React e Tailwind CSS.

## Como rodar o projeto

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Extraia este arquivo ZIP.
3. Copie a imagem da Yzai (`image_5e6afc.png`) que você possui para dentro da pasta `public/`.
4. Abra o terminal na pasta extraída (`yz-app`) e instale as dependências:
   ```bash
   npm install
   ```
5. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
6. Acesse o endereço local (geralmente `http://localhost:5173`) no seu navegador.
